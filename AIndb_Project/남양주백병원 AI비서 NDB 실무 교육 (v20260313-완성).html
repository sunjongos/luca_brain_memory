필수 엔진 원클릭 자동 설치 (Node, Git, Python)

에이전트만 있다고 일할 수 있는 게 아닙니다. MCP(외부 지능 연결망)를 비롯한 다양한 기능을 원활하게 사용하려면 컴퓨터의 핵심 엔진들이 필요합니다.

⚙️ 왜 이 프로그램들이 필요한가요? (초간단 요약)

🟢 Node.js (노드): 여러 AI 도구와 MCP 프로그램들을 실행시켜 주는 '가동 모터'입니다. 이게 없으면 확장 프로그램이 켜지지 않습니다.
🟢 Git (깃): 전 세계 개발자들이 소스코드를 올려두는 저장소(GitHub)에서 최신 AI 기능들을 쏙쏙 가져오기 위한 '배달원' 역할을 합니다.
🟢 Python (파이썬): AI가 똑똑하게 데이터를 분석하고 자동화 스크립트(스킬)를 실행할 수 있게 해주는 'AI의 모국어'입니다.

AIndb 부장님의 자동 설치

"AIndb 부장님! 내가 MCP 기능을 원활하게 사용할 수 있도록 앞서 설명한 필수 엔진들을 한 방에 깔아줘. 1) Chocolatey를 먼저 설치하고, 2) 그걸 통해서 Node.js, Git, Python 최신 버전을 다 설치해버려!"

초보자를 위한 컴맹 탈출 필수 용어 3가지

이거 모르면 대화가 안 됩니다! 간단히 읽고 넘어가세요.

🔑 1. MCP (지능 케이블)

AI가 내 컴퓨터 파일이나 인터넷을 들여다볼 수 있게 해주는 '가상 케이블'입니다.

🔑 2. CLI (주문서)

컴퓨터에게 직접 명령을 내리는 방식입니다. AIndb 부장님이 여러분 대신 주문을 외워줍니다.

5

모든 검색의 시작점, 나만의 RAG: NotebookLM MCP

비서가 똑똑하게 대답하려면 '정확한 교과서'가 필요합니다. 구글의 NotebookLM을 우리의 검색 기반(RAG)으로 삼습니다.

🎯 이 단계의 진짜 목적 (매우 중요!)

  1. 안전성: AI가 엉뚱한 대답(환각 현상)을 하지 않도록, 우리가 직접 넣어준 자료 안에서만 답을 찾게 하는 RAG(검색 증강 생성) 시스템을 구축합니다.
  2. 나만의 노트 제작: NotebookLM 웹사이트에 들어가 새 '노트'를 만들고, 병원 매뉴얼이나 필요한 출처 파일들을 업로드해 둡니다.
  3. 검색의 시작점: 세팅이 끝나면, AI 비서는 모든 외부 자료 검색이나 질문의 시작을 무조건 이 NotebookLM MCP를 통해 수행하게 됩니다.
"AIndb 부장님! 내가 미리 만들어둔 NotebookLM 노트들을 연동할 수 있게 'NotebookLM MCP'를 설치해 줘. 그리고 앞으로 검색이 필요할 때는 최우선적으로 이 MCP를 통해서 내 자료를 먼저 검색해!"

가장 강력한 무기: 구글 워크스페이스 연동 (GWS CLI 방식)

비서가 내 구글 메일과 캘린더, 문서를 요약하고 알아서 일정을 잡도록 만드는 핵심 단계입니다. 미리 말씀드립니다. 이 단계가 가장 낯설고 어려운 난관입니다. 하지만 이것만 넘으면 진정한 AI 비서가 탄생합니다!

⚠️ 주의: MCP 방식이 아닌 GWS CLI 방식을 사용합니다!

구글 연동은 흔히 쓰이는 MCP 플러그인 방식으로는 오류가 잦고 병원 보안망에서 작동하지 않을 수 있습니다. 따라서 우리는 조금 복잡하지만 가장 빠르고 확실하며 강력한 GWS CLI (Command Line Interface) 방식으로 직접 연결합니다. 비서가 터미널에서 구글과 직접 통신하는 구조입니다.

영상 가이드 (필수 시청)

글만 보고 따라 하기엔 구글 사이트가 너무 복잡합니다. 아래 영상을 틀어놓고 화면을 정지해가며 똑같이 따라 하시는 것을 강력히 추천합니다!

▶ [유튜브] Google Workspace API 및 credentials.json 발급 완벽 가이드

GWS CLI 출입증 발급 4단계 핵심 요약

  1. 프로젝트 생성 (집 짓기): 구글 클라우드 콘솔에서 새 프로젝트를 만듭니다.
  2. API 라이브러리 (스위치 켜기): Gmail, Calendar, Drive, Docs API를 검색해 각각 '사용 설정'을 누릅니다.
  3. OAuth 동의 화면 (각서 쓰기): User Type을 '외부(External)'로 설정하고 내 이메일을 테스트 사용자로 등록합니다.
  4. JSON 다운로드 (출입증 받기): 'OAuth 클라이언트 ID'를 생성(데스크톱 앱)하고 다운로드한 파일 이름을 credentials.json으로 바꿔 바탕화면에 둡니다.

AIndb 연동 명령 (실행!)

"AIndb 부장님! 바탕화면에 있는 `credentials.json` 파일을 가져와서 내 구글 워크스페이스를 GWS CLI 방식으로 완벽하게 연동해 줘. 연동이 끝나면 오늘 도착한 메일 중 중요한 것 3개만 요약해서 브리핑해 줘."

나만의 업무 매뉴얼 만들기: Workflow (워크플로우)

구글 연동에 성공하셨나요? 그런데 이 긴 지시를 매번 치려면 번거롭겠죠. 일하는 '순서'를 하나의 세트로 묶어두는 마법입니다.

  1. 방금 채팅창에 입력했던 행동들을 AI에게 하나로 묶어달라고 지시합니다.
"AIndb야, 우리가 방금 '구글 메일 요약 -> 내일 일정 브리핑' 했던 과정을 /morning_briefing 이라는 파일 이름의 워크플로우로 만들어줘."
  1. AI가 알아서 morning_briefing.md 라는 작업 명세서를 생성합니다.
  2. 이제 다음날 아침엔 길게 말할 필요 없이 "/morning_briefing" 딱 한 마디만 채팅창에 치면 모든 업무가 자동으로 수행됩니다!
8

비서에게 특수 무기 지급: Skill (스킬)

워크플로우가 '순서'라면, 스킬(Skill)은 AI가 쓸 수 있는 완전히 새로운 능력입니다.

⚔️ 스킬(Skill) 예시

  • 텔레그램 스킬: 결과를 내 스마트폰 텔레그램으로 즉시 전송
  • 네이버 검색 스킬: 최신 의료 뉴스 및 병원 평판 실시간 모니터링
  • 유튜브 분석 스킬: 우리 병원 관련 영상의 댓글 반응 자동 분석

파이썬 코드(.py)로 된 이 '스킬 무기'를 AI의 Skill 폴더에 넣기만 하면, 비서는 즉시 새로운 능력을 발휘하기 시작합니다!

9

스스로 일어나는 시스템: Cron (자동 실행)

진정한 자동화의 꽃은 '내가 시키지 않아도 알아서 돌아가는 것'입니다.

  1. 윈도우의 '작업 스케줄러'를 이용해 비서의 출근 시간을 맞춥니다.
  2. 매일 아침 8시! 내가 클릭하지 않아도 비서가 알아서 출근합니다.
  3. AIndb가 깨어나 7단계의 /morning_briefing을 실행하고, 8단계의 텔레그램 스킬로 결과를 전송합니다.

🎉 인간-AI 협업 시스템 완성! 🎉

이제 단순 반복 업무는 비서에게 맡기고, 원장님은 더 중요한 창의적 의사결정에 집중하세요.

중앙 정책 자동 동기화 (Daily Sync)

병원 전반의 일관성을 유지하는 AIndb만의 핵심 기능입니다.

Top-Down 지휘 체계

  1. 비서는 매일 아침 업무 시작 전 '병원 중앙 서버(Port 8888)'에 먼저 접속합니다.
  2. 전산팀에서 등록한 "오늘의 중요 보안 지침"이나 "영역별 업무 가이드"를 수신합니다.
  3. 경영진의 최신 정책이 있다면 비서는 스스로 Global Instruction을 업데이트하여 즉시 업무에 반영합니다.
