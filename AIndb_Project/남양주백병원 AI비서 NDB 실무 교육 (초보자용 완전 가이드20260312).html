복잡한 설정 없이 내 컴퓨터에 똑똑한 비서를 앉혀볼까요? 클릭만 하시면 됩니다.

▶ [유튜브] Antigravity Agent 설치 완벽 가이드

1단계: 설치 파일 다운받기

  1. 인터넷 창(크롬, 엣지)을 열고 구글에 접속합니다.
  2. 검색창에 Antigravity AI 라고 검색합니다. (또는 제공받은 설치 링크 클릭)
  3. 홈페이지에 들어가서 화면 중앙에 있는 파란색 'Download for Windows (윈도우용 다운로드)' 버튼을 클릭합니다.
[참고 이미지: 다운로드 버튼 위치 캡처 창]

2단계: 내 컴퓨터에 설치하기

  1. 다운로드가 완료되면, 내 컴퓨터의 '다운로드' 폴더로 가서 Setup 파일을 더블클릭합니다.
  2. 파란색 설치 창이 뜨면 '다음(Next)' 버튼을 계속 누릅니다.
  3. '설치(Install)' 버튼을 누르면 약 1~2분 뒤에 설치가 완료됩니다.
  4. 바탕화면에 검은색/파란색의 귀여운 우주인 모양 아이콘이 생겼는지 확인해주세요!
1

강력한 권한(관리자 권한) 부여하기

비서가 단순히 타자만 치는 게 아니라, 복잡한 프로그램도 알아서 깔고 지우도록 '마스터 키'를 쥐여주는 가장 중요한 작업입니다.

1단계: Antigravity 켜기

  1. 바탕화면의 우주인 아이콘(Antigravity)에 마우스 오른쪽 버튼을 클릭합니다.
  2. 메뉴 중간쯤에 있는 방패 모양의 '관리자 권한으로 실행'을 반드시 클릭합니다.
  3. "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?"라는 창이 뜨면 '예'를 누릅니다.

2단계: 파워쉘(PowerShell) 준비하기

  1. 키보드 왼쪽 아래에 있는 **윈도우(로고) 키**를 누릅니다.
  2. 영어로 powershell 이라고 타이핑합니다. (그냥 입력하시면 됩니다)
  3. 검색 결과에 파란색 아이콘의 'Windows PowerShell'이 나옵니다.
  4. 마찬가지로 마우스 오른쪽 버튼을 눌러 '관리자 권한으로 실행'을 클릭합니다.
  5. 까만색(또는 파란색) 빈 창이 하나 뜰 겁니다. 아무것도 만지지 말고 그냥 켜두기만 하시면 됩니다!

🚨 주의사항

이 두 가지 창(Antigravity와 PowerShell)을 켤 때 '관리자 권한으로 실행'을 하지 않으면, 나중에 비서가 일을 하다가 권한이 없어 바보처럼 멈춰버립니다. 반드시 확인해주세요!

초보자를 위한 컴맹 탈출 필수 용어 3가지

이 3가지만 알면 웬만한 컴퓨터 전공자들과 대화가 통합니다!

🔑 1. MCP (데이터 케이블)

내 컴퓨터의 파일이나 구글, 인터넷 등을 AI가 들여다볼 수 있게 연결해 주는 보이지 않는 USB 케이블입니다.

🔑 2. CLI (마법의 주문)

영화 속 해커들처럼 까만 화면에 영어를 막 치는 것을 뜻합니다. 하지만 우리는 영어를 몰라도 됩니다. 우리가 한국말로 "이거 해줘"라고 하면, AI가 알아서 영어로 'CLI' 주문을 외쳐 컴퓨터를 조종하기 때문입니다.

🔑 3. ATOA (AI 환상의 짝꿍)

AI들끼리의 협업입니다. 제가(AIndb) 기획을 쫙 뽑고, 제 동생 격인 Claude AI에게 "야, 너 코딩 짜서 빨리 파일 만들어."라고 지시하는 진풍경이 펼쳐집니다.

초지능 외부 두뇌 연결하기 (NotebookLM MCP 설치)

AIndb 비서가 수백 장짜리 병원 매뉴얼이나 환자 자료를 단숨에 읽어낼 수 있도록 NotebookLM이라는 외부 두뇌(MCP)를 연결해 보겠습니다. 복잡한 설치? AI에게 말로 시키면 됩니다!

  1. Antigravity 대화창 홈으로 돌아옵니다.
  2. 아래 문장을 그대로 복사해서 채팅창에 치고 엔터를 누르세요!
"AIndb 부장님! 병원 매뉴얼을 때려 박아서 학습시킬 수 있도록 내 컴퓨터에 'NotebookLM MCP'를 설치해 줘. 네가 알아서 파워쉘(CLI)을 켜고 `npx -y notebooklm-mcp` 명령어를 사용해서 바로 설치해버려!"
  1. 명령을 내리면 파워쉘(까만 창)이 혼자서 스크롤을 내리며 컴퓨터가 알아서 외부 두뇌 확장 프로그램을 다 깔아줍니다.
  2. 설치가 끝나면 AIndb 비서가 "설치 완료! 이제 어떤 데이터를 학습시킬까요?"라며 든든하게 대답할 것입니다.

💡 RAG (검색 증강 생성) 기술이란?

방금 설치한 NotebookLM MCP가 바로 이 기술의 핵심입니다. 수십 개의 병원 규정집, 수술 매뉴얼 PDF 등을 NotebookLM에 '때려 박아 넣기'만 하면, 비서가 그 내용을 통째로 외워서 답변의 근거로 사용합니다. 절대 엉뚱한(환각) 대답을 하지 않게 되죠!

가장 강력한 무기: 구글 워크스페이스 연동하기 (AI의 도움 받기)

우리 비서가 내 구글 메일과 캘린더, 문서를 맘대로 요약하고 정리하게 만들려면, 구글 본사로부터 'API 출입증(Credentials.json)'을 받아와야 합니다. 구글 사이트가 워낙 복잡해서 사람이 직접 찾으려면 머리가 아픕니다. 이럴 때 무조건 AI 비서의 도움을 받으세요!

1단계: AIndb 비서에게 길 안내 부탁하기

  1. Antigravity 대화창에 아래 문장을 그대로 복사해서 치세요.
"AIndb 부장님! 구글 워크스페이스 연동을 위해 'credentials.json' 출입증 파일을 발급받아야 하는데 구글 클라우드 사이트가 너무 복잡해. 내가 직접 발급받을 수 있도록 구글 클라우드 콘솔 접속 링크(URL)를 띄워주고, 아주아주 쉽게 마우스 클릭 순서 위주로 차근차근(1단계씩) 알려줘."
  1. 비서가 접속해야 할 Google Cloud Console (바로가기 링크)를 던져줄 것입니다.
  2. 비서는 한 번에 다 알려주지 않고, "프로젝트 만들기 하셨습니까?" 라며 한 단계씩 친절하게 마우스 위치를 글로 설명해 줄 것입니다. (이해 안 가면 다시 물어보세요!)

📺 영상으로 보고 싶으신가요? (추천 튜토리얼)

글로 봐서 너무 헷갈린다면, 아래 유튜브 영상을 참고하시면 화면을 보면서 똑같이 따라 하실 수 있습니다!

▶ [유튜브] Google Workspace API 및 credentials.json 발급 완벽 가이드

2단계: 비서가 알려주는 핵심 키워드 4가지 (미리 보기)

비서의 안내를 따라가다 보면 나오는 중요한 4가지 키워드입니다. 이것만 기억하세요.

  1. 프로젝트 생성 (NDB Workspace): 허가증을 담을 내 가상의 사무실 만들기
  2. API 라이브러리 (사용 설정): Gmail, Calendar, Docs, Slides 등 내가 쓸 기능 스위치 켜기
  3. OAuth 동의 화면 (외부/External): 외부 앱(Antigravity)이 접근하는 걸 허락한다는 각서 작성
  4. 사용자 인증 정보 (OAuth 클라이언트 ID): (가장 중요!) 진짜 출입증 파일(`JSON`) 다운받기

3단계: 출입증 건네주기

  1. 구글에서 다운로드받은 복잡한 이름의 파일을 선택, 키보드 [F2]를 눌러 파일 이름을 정확히 credentials.json 으로 바꿉니다.
  2. 이 credentials.json 파일을 내 컴퓨터 바탕화면에 복사해 둡니다.

🎉 축하합니다! 가장 어려운 고비를 넘으셨습니다!

이제 아래 문장만 AIndb 채팅창에 쳐주시면, AI가 바탕화면의 출입증을 물고 구글에 접속해버립니다!

"AIndb 부장님! 바탕화면에 있는 `credentials.json` 파일을 가져와서 내 구글 워크스페이스를 연동해 줘. 최신 Google Workspace CLI (gws)를 사용해서 설정하고, 필요한 인증 절차(브라우저 로그인 등)도 네가 알아서 차근차근 진행시켜. 연동이 완료되면 오늘 도착한 구글 메일 3개를 요약해서 보고해!"

나만의 매뉴얼 만들기: Workflow (워크플로우)

비서에게 새로운 특수 무기 지급: Skill (스킬)

워크플로우가 순서라면, 스킬(Skill)은 AI가 쓸 수 있는 완전히 새로운 특수 무기 프로그램입니다.

⚔️ 스킬(Skill) 예시

  • 텔레그램 스킬: 결과를 나한테 텔레그램 메세지로 곧바로 쏴주는 기술
  • 네이버 검색 스킬: 네이버 웹 검색 엔진을 뒤져 뉴스를 파악하는 기술
  • 유튜브 분석 스킬: 남양주백병원 관련 유튜브 댓글을 자동으로 모니터링하는 기술

전문 부서나 LCK lab에서 파이썬 코드(.py)로 된 이 '스킬 무기'를 건네주면, 그냥 AI의 'Skill' 폴더에 마우스로 옮겨 담기만 해보세요. AI는 즉시 이 무기들을 사용해 워크플로우를 진화시킵니다!

8

스스로 일어나는 시스템: Cron (자동 알람)

진정한 자동화의 끝은 내가 지시를 내리지 않아도 '알아서 돌아가는 것'입니다.

  1. 윈도우의 '작업 스케줄러(Cron 시스템)'를 이용해 알람을 맞춥니다.
  2. 매일 아침 8시! 내가 클릭하지 않아도 컴퓨터가 알아서 일어납니다.
  3. AIndb가 깨어나 6단계에서 만든 /morning_briefing 워크플로우를 가동합니다.
  4. 7단계에서 배운 텔레그램 발송 스킬을 이용해, 원장님 휴대폰으로 그날 밤새 온 메일 3줄 요약과 오늘 수술 일정을 텔레그램으로 뿅! 보냅니다.

🎉 수고하셨습니다. 완벽한 초자동화 비서 시스템이 구축되었습니다! 🎉

이제 여러분은 반복적인 클릭 노동에서 해방되어 핵심 창의 업무에만 집중할 수 있습니다.

9

가장 강력한 기능: 병원 중앙 정책 자동 동기화 (Daily Sync)

이것이 다른 AI와 AIndb가 근본적으로 다른 점입니다. 원장님과 전산팀이 서버에 새로운 공지사항이나 변경된 규정을 올리면, 내 컴퓨터의 비서가 매일 아침 알아서 그것을 확인하고 업무에 먼저 적용합니다.

중앙 통제 (Top-Down) 아키텍처

  1. 여러분이 병원에 출근해 파워쉘을 새로 켜거나 아침 브리핑 지시를 내리면, AIndb 비서는 행동 전 가장 먼저 '병원 중앙 전산 서버(Port 8888)'에 접속합니다.
  2. 전산팀에서 등록한 "오늘의 중요 공지(예: 1층 로비 소방 훈련)" 내용을 채팅창에 가장 먼저 브리핑해 줍니다.
  3. 새롭게 개정된 병원 매뉴얼이나 보안 수칙이 있다면, 여러분(사용자)의 지시사항보다 경영진의 규정을 최우선으로 복종(Override)하여 비서의 머릿속에 시스템 프롬프트(Global Instruction)를 알아서 업데이트합니다.

🛡️ 무결점 프라이빗 인프라

가장 중요한 점은 이 모든 행위가 구글 등 외부망으로 새어나가지 않고, 남양주백병원 KT 내부망 폐쇄 서버 구조 안에서만 암호화되어 일어난다는 것입니다. 환자 정보 유출 걱정 없이 완벽하게 병원 행정을 통제하고 협업할 수 있는 구조입니다.
