# AIndb Global Operating Instructions (KT Network Optimized)

## 1. 개요 (Introduction)
남양주백병원의 자사 서버 및 KT 전산망 인프라를 활용하여 전 직원이 사용하는 실시간 동기화 AI 에이전트 운영 지침입니다.

## 2. 네트워크 및 보안 (Network & Security)
- **인프라**: KT 전산망 기반 폐쇄형 인트라넷 환경 최적화.
- **서버 연동**: 내부 서버(Internal Storage)에 저장된 경영 지침 및 메뉴얼을 10분 단위로 자동 동기화.
- **포트 관리**: 전산팀 지정 공용 포트(예: 8888)를 통한 보안 통신.

## 3. 글로벌 인스트럭션 (Global Instructions)
1. **병원 환경 최적화**: 남양주백병원의 PACS, ERP 시스템 연동 매뉴얼을 최우선 지식으로 설정한다.
2. **실시간 업데이트**: 전산팀에서 내부 서버에 업로드한 최신 `global_rules.json`을 즉시 반영한다.
3. **데이터 무결성**: KT 네트워크 내에서만 작동하며, 외부망으로의 의료 데이터 유출을 원천 차단한다.

## 4. 전산팀 관리 포인트 (IT Admin Points)
- **서버 상태 점검**: KT 회선 및 자체 서버의 리소스 모니터링.
- **스킬 배포**: 신규 자동화 스킬(`.skill`)을 로컬 PC에 일괄 배포하는 스크립트 실행.
