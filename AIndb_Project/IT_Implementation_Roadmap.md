# AIndb 전산팀 실행 가이드 (IT Technical Roadmap)

## 1. 개요 (Executive Summary)
본 가이드는 남양주백병원 전산팀이 AIndb 시스템을 KT 전산망 및 자체 서버 인프라에 안착시키기 위한 기술적 단계와 보안 요구사항을 정의합니다.

## 2. 서버 사이드 인프라 구축 (Server-Side Setup)
### 2.1 중앙 관리 허브 설정
- **호스트**: 내부 전산실 전용 서버 (Windows/Linux)
- **포트 개방**: 내부망 전용 `8888` 포트 개방 (TCP) - 에이전트 동기화용
- **디렉토리 구조**:
  - `/AIndb/config/global_rules.json`: 실시간 경영 지침 데이터
  - `/AIndb/skills/`: 배포용 .skill 파일 저장소
  - `/AIndb/logs/`: 전사 에이전트 활동 로그 수집

### 2.2 실시간 동기화 인터페이스
- 에이전트가 서버에 접속할 때 최신 지침을 JSON 형태로 반환하는 경량 API 또는 정적 파일 서빙 환경 구성.
- 경영진이 텍스트 파일을 수정하면 즉시 업데이트되도록 파일 시스템 감시(Watcher) 스크립트 적용 권장.

## 3. 사용자 주도 설치 및 교육 (Self-Onboarding)
- **방식**: 전산팀이 일괄 설치하는 대신, 직원이 배포된 설치 파일과 가이드를 보고 직접 PC에 세팅.
- **교육 자료**: `남양주백병원 AI비서 NDB 실무 교육 (초보자용 완전 가이드).html` 배포.
- **이점**: IT 팀의 설치 리소스를 90% 이상 절감하며, 사용자 교육을 동시에 수행 가능.

## 4. Port 8888: TOP-DOWN 지휘 관리 체계
### 4.1 중앙 통제 허브 (Instruction Hub)
- **역할**: 경영진이 내리는 업무 가이드라인, 글로벌 인스트럭션, 병원 규칙 등을 일괄 배포.
- **작동 원리**: 모든 직원 PC의 Antigravity 에이전트가 실행 시 서버의 `8888` 포트를 통해 최신 정책을 자동으로 다운로드(Fetch).
- **데이터 관리**: 전산팀은 서버 내의 `global_rules.json` 파일만 관리함으로써 전사 에이전트를 실시간 통제 가능.

### 4.2 네트워크 및 보안 정책 (KT Network)
- **KT 전산망 최적화**: 내부망 내에서만 Port 8888 통신이 가능하도록 설계하여 보안성 극대화.
- **화이트리스트**: 경영진이 승인한 규칙 및 매뉴얼 외의 외부 데이터 접근 통제.

## 5. 실행 타임라인 (Suggested Timeline)
1. **Week 1**: 서버 인프라 구축 및 포트 개방 테스트.
2. **Week 2**: 5대 규모의 PC에서 파일럿 테스트 및 KT망 안정성 확인.
3. **Week 3**: 전 부서 순차적 배포 및 사용자(의료진/행정직) 교육 시작.
4. **Week 4**: 상시 모니터링 체계 가동 및 1차 성과 리포트 산출.
