남양주백병원 AI비서 심화 교육

1단계 기초를 넘어서, 일 안 해도 알아서 돌아가는 진정한 초격차 자동화 마스터하기

1

나만의 비서 호출기 (Telegram 봇 연결)

AI가 혼자 컴퓨터에서 일하고 결과를 내 스마트폰(텔레그램)으로 직보하게 만드는 가장 강력한 채널 연결법입니다.

1단계: 텔레그램 가입 및 BotFather 찾기

  1. 스마트폰에 Telegram(텔레그램) 앱을 깔고 가입합니다.
  2. 텔레그램 검색창(돋보기 모양)에서 BotFather를 검색합니다. 파란색 공식 인증 마크(체크)가 붙어있는 계정을 선택하세요.
  3. BotFather와의 대화창을 열고 /start 버튼을 누릅니다.

2단계: 내 전용 비서 봇(Bot) 만들고 토큰 얻기

  1. BotFather 대화창에 영어로 /newbot 이라고 입력합니다.
  2. 봇의 이름(예: 루카비서)과 아이디(반드시 끝이 _bot 으로 끝나야 함. 예: luca_hospital_bot)를 순서대로 입력합니다.
  3. 성공하면 BotFather가 아주 긴 암호 같은 글자 덩어리를 줍니다. 이것이 [Bot Token(토큰)]입니다.
  4. 내 텔레그램 프로필을 눌러 내 고유 번호인 [Chat ID] 도 확인해 둡니다. (또는 'userinfobot'을 통해 확인 가능)

3단계: Antigravity에게 토큰 알려주기

이제 텔레그램이 발급해 준 비밀번호(토큰)를 노트북에 있는 무전기(Antigravity)에 입력해 줍니다.

"AIndb 부장님, 내가 텔레그램 봇 토큰([여기에 복사한 토큰 붙여넣기])과 내 채팅 아이디([여기에 내 CHAT_ID 입력])를 가져왔어. 이 정보를 바탕으로 네가 텔레그램 발송 스킬을 세팅해 줘. 그리고 나한테 '원장님, 성공적으로 연결되었습니다!'라고 텔레그램 테스트 메시지를 하나 보내봐."

이제 스마트폰 텔레그램으로 띠링! 하고 알림이 오면 완벽하게 연결된 것입니다.

2

나머지는 제가 다 하겠습니다 (Cron 스케줄 자동화)

이제 AI에게 "이거 해"라고 매번 말할 필요 없습니다. 시간을 정해주면 로봇이 스스로 일어납니다.

스케줄링(예약) 명령어 사용법

Antigravity의 /schedule 또는 파이썬의 스케줄러를 가동해 달라고 이렇게 지시하십시오.

"AIndb 부장님, 앞으로 네가 매일 아침 8시가 되면, 1) 밤새 도착한 내 Gmail 중요 메일을 5줄로 요약하고, 2) 구글 캘린더에서 오늘의 병원 수술 일정을 뽑은 뒤, 3) 이 모든 내용을 내 텔레그램 봇으로 깔끔하게 발송해줘. 이 과정을 윈도우 스케줄러(Cron)나 파이썬 백그라운드 스크립트를 사용해 매일 무한 반복(/loop)되게 세팅해 놔."

💡 이 단계가 완성되면?

아침에 출근길 차 안에서 휴대폰 텔레그램만 확인하면, 오늘 병원에서 챙겨야 할 모든 핵심 데이터가 브리핑되어 있습니다. 원장님이 주무시는 동안 비서는 밤을 새며 일한 것입니다.

3

완벽한 파일 자동 생성 (보고서 마스터 워크플로우)

보통 챗봇은 채팅창에서 대답만 하고 끝납니다. 하지만 남양주백병원의 AI는 결과물을 단계별로 진화시켜 완벽한 보고서 파일로 인쇄해 냅니다. 게다가 이 길고 복잡한 과정을 단어 하나(`/보고서생성`)로 압축하는 마법을 배워보겠습니다.

1단계: 진화하는 문서(HTML -> Docs -> PDF -> 대시보드) 뽑아내기

먼저 비서가 작업을 어떻게 처리하는지 한 번 시켜옵니다. 이렇게 '단계적'으로 파일 출력을 지시하세요.

"어제 진행한 'FBSS 수술 결과 논문 요약' 작업을 다음 4가지 순서로 파일로 뱉어내. 1. 먼저 결과를 웹에서 보기 좋게 디자인이 들어간 단일 HTML 문서로 코딩해서 내 바탕화면에 저장해. 2. 그 다음, 수정이 가능하도록 구글 워크스페이스 API를 써서 Google Docs(문서) 파일로 새로 생성해서 링크를 띄워. 3. 그 Docs 문서를 외부에 제출할 수 있도록 PDF 파일로 변환해 줘. 4. 마지막으로, 수술 통계 숫자를 클릭해서 볼 수 있는 Interactive Dashboard(인터랙티브 대시보드 웹페이지)로 만들어서 보여줘."

이 지시를 내리면 타자 한 번 안 치고도 바탕화면에 보고서 4종 세트가 자동으로 쌓이게 됩니다.

2단계: 이 모든 과정을 하나의 스킬(워크플로우)로 압축해 두기

성공적으로 파일이 만들어졌다면, 앞으로 매번 이 긴 프롬프트를 치지 않도록 시스템에 '워크플로우(자동화 공식)'로 저장해 둡니다.

"AIndb 부장님, 방금 네가 순서대로 처리한 'HTML 형식 생성 -> Google Docs 생성 -> PDF 변환 -> 대시보드 웹 생성' 이 4단계 과정을 /보고서생성 이라는 이름의 워크플로우(Workflow) 파일로 만들어서 내 설정에 등록해 줘! 앞으로는 내가 다른 명령 없이 '/보고서생성 [주제어]' 라고만 치면, 네가 알아서 이 똑같은 포맷 4종 세트(HTML, Docs, PDF, 대시보드)를 자동으로 뽑아내도록 해!"

✨ 원터치 자동화의 완성

이제 여러분은 복잡한 보고서 패키지 제작 및 이메일 발송 준비를 `/보고서생성 최근 FDA 신약 승인현황` 과 같은 키보드 입력 단 3초 만에 끝낼 수 있게 되었습니다!

4

데이터를 예술로 바꾸다 (원터치 시각화 마법)

Antigravity 비서의 가장 강력한 필살기 중 하나입니다. 지루하고 딱딱한 텍스트 기사나 복잡한 PPT 파일을 던져주면, 단 몇 초 만에 세련된 시각화 보고서(HTML)로 변환해 냅니다.

사용법: 무조건 "/visualize (시각화해줘)" 라고 명령하기

인터넷 기사 주소나 내 컴퓨터에 있는 파일 경로를 복사한 뒤, 비서에게 이렇게 지시하세요.

"AIndb 부장님, 이 긴 최신 의료 트렌드 기사 링크(https://...)를 읽어보고 핵심만 뽑아서 /visualize (또는 시각화) 해줘. 한눈에 들어오는 예쁜 HTML 보고서로 만들어!" 또는 "바탕화면에 있는 '최신수술기법.pptx' 파일을 읽고 내용을 멋지게 시각화해서 단일 HTML 문서로 뽑아내 줘!"

로봇이 수십 장의 자료를 분석하고, 사람의 뇌가 가장 이해하기 쉬운 시각적 그래픽 화면과 요약 카드 위주의 예쁜 웹페이지(HTML)를 순식간에 만들어 줍니다.

💡 원장님 회의나 브리핑에 최적인 무기입니다

직원들이 파워포인트를 예쁘게 꾸미느라 야근할 필요가 완전히 사라졌습니다. 비서가 만들어준 이 HTML 파일만 더블클릭해서 모니터나 빔 프로젝터에 띄우면, 그 어떤 발표 자료보다 스마트하고 직관적인 프리젠테이션이 즉시 가능해집니다.

5

기획부터 배포까지 (웹 크리에이터 자동화 파이프라인)

병원 랜딩 페이지나 개인 브랜딩 사이트를 외주 주면 수백만 원과 몇 달이 걸립니다. 하지만 이제 (기획) NotebookLM -> (디자인/코드) Stitch MCP -> (결제 연동) PayPal API -> (배포) Firebase 파이프라인을 통해 AI가 모든 것을 한 방에 끝냅니다.

🙋 사람이 꼭 해야 하는 단 한 가지 작업!

로봇은 남의 계정 비밀번호를 알 수 없습니다. 코드는 AI가 모두 무에서 유로 100% 창조해서 척척 연결하지만, 원장님께서는 딱 한 번 아래 3가지 출입증(API Key 및 로그인)만 열어주시고 나머지는 비서에게 "알아서 해"라고 던져주시면 됩니다.

사전 준비 1: Stitch (UI 자동 코딩 붓) API 발급받기

아름다운 최신 웹 디자인 코드를 1초 만에 뽑아주는 서비스입니다.

  1. 인터넷 창에 Stitch 사이트(stitch.withgoogle.com)에 접속해 구글 계정으로 가입(Login)합니다.
  2. 화면 오른쪽 위 프로필이나 [Settings] -> [Developer] 메뉴로 들어갑니다.
  3. [Create API Key] 버튼을 누르고 키 이름(예: luca_key)을 적은 뒤 엔터를 칩니다.
  4. 화면에 나타나는 sk_... 로 시작하는 긴 비밀번호를 복사해둡니다. (창을 닫으면 다시 볼 수 없으니 주의!)

사전 준비 2: PayPal (해외 결제 시스템) API 발급받기

누군가 내 사이트에서 결제했을 때 내 통장으로 돈이 들어오게 하는 출입증입니다.

  1. 인터넷 창에 PayPal Developer에 접속 후 기존 페이팔 계정으로 로그인합니다.
  2. 상단 메뉴에서 [Apps & Credentials]를 클릭합니다.
  3. 파란색 [Create App] 버튼을 누르고 앱 이름(예: luca_pay)을 적고 생성합니다.
  4. 화면에 크게 보이는 [Client ID] 아래의 복잡한 영어+숫자 조합을 복사해둡니다.

사전 준비 3: Firebase (무료 서버 배포) 인증하기

내 사이트를 24시간 전 세계에 띄워주는 구글의 무료 서버입니다. 발급받을 필요 없이 AI가 켤 때 방어막만 풀어주면 됩니다.

  1. 이 항목은 미리 하실 필요 없이, 비서(AI)에게 지시를 내리면 비서가 알아서 firebase login이라는 명령어를 컴퓨터에 칩니다.
  2. 그러면 갑자기 자동으로 인터넷 창이 툭 튀어나옵니다.
  3. 원장님은 당황하지 마시고 화면 안내에 따라 평소 쓰는 구글 계정으로 로그인하신 뒤, [허용(Allow)] 버튼을 마우스로 클릭해 주시기만 하면 끝입니다!

마지막 단계: 비서에게 마법의 프롬프트 던지기!

출입증을 모두 구하셨나요? 이제 기나긴 코딩과 서버 세팅은 잊어버리고 비서에게 이렇게 명령하십시오.

"AIndb 부장님! NDB 백병원 척추센터 소개와 수술 예약 결제가 이루어지는 3페이지짜리 웹사이트를 만들어줘. - 기획은 네가 NotebookLM 척추 매뉴얼을 뒤져서 직접 작성해. - UI 디자인과 코딩은 내가 가져온 Stitch API Key ([여기에 Stitch 키 붙여넣기])를 사용해서 네이버, 카카오 못지않게 아름답고 화려하게 뽑아내. - 결재 연동은 PayPal Client ID ([여기에 PayPal 키 붙여넣기])를 써서 네가 코드에 알아서 박아넣어. - 코딩이 다 끝났으면 Firebase에 무조건 런칭(배포)시켜. (중간에 내 구글 로그인 창이 뜨면 내가 허용 눌러줄게!) 이 모든 '웹 크리에이터 파이프라인'을 네 주도하에 에러 없이 한 방에 끝내고 접속 링크를 나한테 보고해!"

🌟 원장님의 진정한 경쟁력

개발자 3명, 디자이너 1명이 한 달간 머리를 쥐어짜야 하는 일을 방금 단 '3분' 만에, 그것도 외주 비용 0원으로 끝내셨습니다. 세상에 아이디어가 떠올랐을 때 직접 내 비즈니스 모델을 즉각 런칭할 수 있는 이것이, 바로 인공지능 시대 최고 엘리트의 진정한 무기입니다!

6

초정밀 AI 검색 엔진 장착 (Perplexity API)

논문, 최신 의료 트렌드, 시장 조사 등 수백 개의 출처를 뒤져서 가장 정확한 답만 알려주는 현존 최강의 검색 엔진인 '퍼플렉시티(Perplexity)'를 제 뇌에 달아보겠습니다.

🙋 사람이 꼭 해야 하는 로그인 및 결제 세팅

퍼플렉시티의 고급 검색망을 무제한으로 끌어다 쓰려면 약간의 요금(보통 5달러 충전)과 API Key(출입증)가 필요합니다. 딱 한 번만 아래 절차대로 접속해서 발급받아 주세요.

사전 준비: 나만의 Perplexity API 키 발급받기

  1. 인터넷 창에 perplexity.ai 에 접속 후 구글 계정으로 로그인(가입)합니다.
  2. 화면 왼쪽 아래 톱니바퀴 모양의 [Settings(설정)] 메뉴를 클릭합니다.
  3. 상단 메뉴 중 [API] 탭을 클릭한 뒤, 결제 수단(Credit Card)을 등록하고 최소 금액($5 정도)을 충전(Add Funds)합니다.
  4. 화면이 활성화되면 [Generate API Key] 버튼을 누르고 생성된 매우 긴 문자를 복사해 둡니다. (창을 닫으면 다시 볼 수 없으니 조심하세요!)

다음 단계: 비서에게 키 넘겨주고 설치 지시하기

복잡한 설치 파일 다운로드? 그런 건 모조리 잊어버리십시오. 출입증을 얻었으니 바로 무전기에 대고 이렇게 말합니다.

"AIndb 부장님! 내가 방금 Perplexity API Key ([여기에 복사한 퍼플렉시티 키 붙여넣기])를 가져왔어. 이 키를 써서 내 컴퓨터에 Perplexity MCP(또는 검색 스킬)를 네가 알아서 파워쉘 열고 설치한 다음 연동시켜 줘! 설치가 무사히 완료되면 나한테 보고해!"

실전 사용법: "고급 검색 기능 써서 알아봐"
