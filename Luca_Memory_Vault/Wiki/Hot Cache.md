[[Hot Cache]]는 [[AI 에이전트]]가 [[LLM Wiki]]와 상호작용할 때 사용되는 작은 임시 메모리 저장 공간입니다 (약 500단어/자). 이는 최근 대화 내용이나 가장 중요하다고 판단되는 정보를 저장하여, 에이전트가 매번 전체 [[Wiki 페이지]]를 크롤링할 필요 없이 관련 문맥을 빠르게 참조할 수 있도록 합니다. [[AI 에이전트]]의 [[토큰 효율성]]을 높이고 응답 속도를 향상시키는 데 기여합니다. 모든 프로젝트에 필수적인 것은 아니며, [[Executive Assistant]]와 같은 상호작용이 많은 에이전트에게 특히 유용합니다.
