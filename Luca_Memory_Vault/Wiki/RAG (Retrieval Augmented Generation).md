[[RAG (Retrieval Augmented Generation)]]는 [[대규모 언어 모델 (LLM)]]의 생성 능력을 보완하기 위해 외부 [[지식 시스템]]에서 정보를 검색하여 답변을 생성하는 기술입니다. 이는 [[시맨틱 검색]]과 [[벡터 데이터베이스]], [[임베딩]] 파이프라인을 활용하는 경우가 많습니다. [[LLM Wiki]]는 전통적인 [[RAG]] 파이프라인과 비교될 때, 수백만 개의 문서를 다루는 기업 규모의 확장에서 [[RAG]]가 더 적합할 수 있지만, 수백 페이지 정도의 잘 인덱싱된 문서에는 [[LLM Wiki]] 방식이 충분하다고 언급됩니다.
