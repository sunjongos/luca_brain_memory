[[Claude Code]]는 [[LLM Wiki]]의 핵심 구성 요소로, [[원본 데이터]]를 [[수집 및 정리]]하고 [[Wiki 페이지]]를 생성하는 역할을 하는 [[대규모 언어 모델 (LLM)]] 기반의 도구입니다. 사용자가 제공하는 [[원본 데이터]] (예: [[YouTube Transcripts]], PDF, 웹 문서 등)를 분석하여 주요 개념을 추출하고, 이들 사이의 [[관계]]를 파악하여 자동으로 [[마크다운 파일]] 형태의 [[Wiki 페이지]]로 변환합니다. 이 과정에서 [[청킹]] 및 [[백링크]] 생성이 이루어지며, [[인덱스]]와 [[로그]]도 관리합니다. 또한, 생성된 위키에 대한 [[Q&A]] 및 [[효율적인 검색]] 기능도 제공합니다.
