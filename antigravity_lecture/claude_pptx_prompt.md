[슬라이드 3: Step 0 - 클릭 3번 다운로드]

  - 1. 구글 검색창에 'Antigravity AI' 검색 (또는 원내 링크 클릭)
  - 2. 홈페이지 중앙 파란색 'Download for Windows' 클릭!
  - 3. 다운로드 폴더에서 Setup.exe 실행 후 '다음(Next)'만 계속 누르기
- 강조: 바탕화면에 '우주인 아이콘' 생기면 성공!
- 시각 자료: 홈페이지의 '다운로드 버튼'을 붉은색 네모 쳐서 확대한 캡처 이미지

[슬라이드 4: Step 1 - 마스터 키(권한) 열어주기]

- 경고: 이 두 가지 창을 '관리자'로 열지 않으면 나중에 에러가 납니다! 꼭 명심하세요.
- 시각 자료: 마우스 우클릭 메뉴에서 '관리자 권한으로 실행'에 노란색 형광펜 칠한 이미지

[슬라이드 5: Step 2 - 나만의 최고 능력자, 'AIndb' 영혼 주입하기]

  - 2. 초록색 [Approve(승인)] 버튼 누르면 비서가 스스로 명함(agent.md)을 만들어 냅니다! 
  - (보너스: 이제 AIndb가 대답할 때마다 환하게 웃는 간호사 로봇 얼굴(아바타)을 띄워줍니다!)

- 시각 자료: 'agent.md' 문서가 두뇌(AI)에 자동으로 쏙 들어가고, 귀여운 병원 로봇 아바타가 웃으며 반겨주는 일러스트

[슬라이드 6: Step 3 - AI 비서 컴맹 탈출 필수 용어]
- 타이틀: 딱 3개만 알면 나도 AI 전문가! (MCP, CLI, ATOA)
- 내용:
  - 1. MCP (데이터 케이블): 내 컴퓨터 파일, 병원 매뉴얼을 AI와 연결해 줌.
  - 2. CLI (마법의 주문): 해커처럼 까만 화면 치는 것. (단, AI가 우리 대신 한글을 영어 명령어로 쳐줌!)
  - 3. ATOA (환상의 짝꿍): 기획하는 AI와 일하는 AI(Claude)의 콜라보.
- 시각 자료: 어려운 영어가 아닌 USB 케이블, 요술봉(마법 주문), 콤비 캐릭터(ATOA) 아이콘

[슬라이드 7: Step 4 - 초지능 외부 두뇌 연결하기 (NotebookLM MCP 설치)]
- 타이틀: 수백 쪽짜리 매뉴얼 통째로 삼키는 'RAG 기술' 장착하기
- 내용:
  - Antigravity 채팅창에 이렇게 치세요: "AIndb 부장님! 병원 매뉴얼을 학습시킬 수 있도록 내 컴퓨터에 'NotebookLM MCP'를 설치해. 파워쉘 켜고 `npx -y notebooklm-mcp` 써서 알아서 당장 설치해버려!"
  - 초록색 [Approve(승인)] 버튼만 누르면, 파워쉘(까만 창)이 혼자서 돌아가며 알아서 외부 두뇌 확장 프로그램을 다 깔아줍니다.
  - 🧠 RAG (검색 증강 생성) 란? : 수십 개의 수술 매뉴얼 PDF 등을 NotebookLM에 '때려 박아 넣기'만 하면, 비서가 그걸 줄줄 외워서 답변하는 엉뚱한 말방지 마법!
- 시각 자료: 방대한 서류 더미(PDF)가 파이프로 연결되어 로봇의 뇌(NotebookLM) 속으로 빛을 내며 빨려 들어가는 3D 일러스트
