전산팀 AIndb 중앙 제어 서버 세팅 가이드

남양주백병원 KT 폐쇄망 기반 Top-Down AI 에이전트 통제 시스템 구축 (Port 8888)

시스템 아키텍처 개요 (Top-Down Control)

본 문서는 경영진의 지침과 병원 최신 매뉴얼을 전 직원의 AI 비서(AIndb)에게 동시에, 강제적으로 적용하기 위한 중앙 집중식 제어 서버 구축 가이드입니다.

💡

핵심 설계 사상 (One Voice, One Rule)

각 직원(PC)이 설치한 개별 AIndb 에이전트들은 매일 아침(혹은 수시로) 전산팀이 관리하는 특정 IP/Port(8888)에 접속하여 최신 설정 파일(JSON)을 받아옵니다. 이 중앙의 지침(Global Instruction)은 로컬 사용자의 지시를 덮어쓰며, 가장 최우선되는 헌법으로 작용합니다.

시스템 요구사항

  • 네트워크 KT 전산망(내부망)에서 접근 가능한 내부 서버 1대 확보
  • 포트 TCP 8888 오픈 (내부망 한정)
  • 서비스 단순 HTTP GET 요청에 JSON 파일(.json)을 반환할 수 있는 웹 서버 (Nginx, Apache, Node.js, Python Flask 등 무관)

REST API 엔드포인트 명세

중앙 서버는 아래 엔드포인트를 노출하여 각 직원의 에이전트가 정보를 페치(Fetch)할 수 있도록 응답해야 합니다.

API 규격

  • Endpoint: http://[전산팀_서버_IP]:8888/api/v1/agent-config
  • Method: GET
  • Content-Type: application/json

JSON 응답 구조 (Response Schema)

서버는 반드시 아래와 같은 포맷의 JSON 데이터를 반환하도록 세팅해 주십시오.

주의사항

global_instruction_override 배열의 내용은 현장 에이전트 판단의 최상위 기준이 됩니다. 프롬프트 인젝션을 막고 보안을 통제하는 핵심 텍스트이므로 전산팀장 및 원장님의 최종 컨펌을 받은 내용만 기입하십시오.

현장 PC 연결 및 동기화 플로우

중앙 서버가 구축되면, 직원(로컬 PC) 측에서 세팅된 AIndb의 작동 방식은 다음과 같습니다.

  1. 직원이 아침에 PC를 켜고 /morning_briefing (모닝 브리핑 워크플로우) 또는 기타 업무를 지시합니다.
  2. AIndb 에이전트(백그라운드 Python/Node 스크립트)는 타스크 시작 전 http://[서버_IP]:8888/api/v1/agent-config를 조회합니다.
  3. 서버에서 받아온 새로운 daily_announcements를 채팅창 화면에 가장 먼저 팝업으로 띄워줍니다.
  4. 받아온 global_instruction_override 텍스트를 AI 메모리(System Prompt)에 주입하여, 그 날 하루 동안 병원 규정에 한 치도 어긋나지 않게 답변하고 행동하도록 제어합니다.

스킬(Skill) 강제 배포 가능

JSON 구조 내 forced_skills_update 필드를 활용하면, 전산팀에서 새롭게 개발한 자동화 스크립트(.py)를 직원 100명의 PC에 동시다발적으로 자동 다운로드 및 패치할 수 있습니다.
