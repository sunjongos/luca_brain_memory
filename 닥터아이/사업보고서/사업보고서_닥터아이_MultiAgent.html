1. 사업 개요

본 사업은 파이헬스케어-LCK 연구소가 개발한 AI 안저진단 솔루션 닥터아이(Doctor Eye)를 핵심 엔진으로, Multi-Agent AI 시스템을 결합하여 당뇨 환자의 눈 질환을 자동화된 3단계 워크플로우로 관리하는 세계 최초의 의료 AI 오케스트레이션 플랫폼을 구축하는 것을 목표로 합니다.

2. 문제 정의 — 왜 지금인가

2.1 당뇨 합병증 실명의 위험성

대한민국 당뇨 환자는 약 600만 명으로, 이 중 당뇨성 망막증 발생률은 진단 10년 후 30%에 달합니다. 당뇨 합병증 중 실명은 삶의 질을 가장 극단적으로 파괴합니다. 신장부전은 투석으로 대체 가능하지만, 시력은 한 번 잃으면 회복이 불가능합니다.

3. 솔루션 — 닥터아이 + Multi-Agent 시스템

3.1 시스템 개념

닥터아이 AI 진단 결과를 트리거로, 복수의 전문 AI 에이전트가 병렬(Parallel) 및 직렬(Sequential) 방식으로 협업하여 진료 워크플로우를 자동 처리합니다. 의사는 중요한 의사결정(처방 최종 승인, 협진 서명)만 Human-in-the-Loop 방식으로 개입합니다.

🔵 Layer 1 — 진단 레이어 (닥터아이 AI)

안저 촬영 → 4대 안질환 AI 분석 → 위험도 스코어링 → 결과 분기 판단 (완전 자동)

🟡 Layer 2 — 처리 레이어 (Multi-Agent 병렬 실행)

Prescription Agent(처방 초안) + ECAS Agent(혈관 평가) + Notify Agent(환자 문자) + Scheduler Agent(재방문 예약) — 동시 병렬 실행

🟣 Layer 3 — 승인 레이어 (Human-in-the-Loop)

처방 최종 승인 · 협진 의뢰 서명 · 고위험군 뇌 MRI 의뢰 — 반드시 의사 개입

🟢 Layer 4 — 학습 레이어 (Feedback Loop)

의사 수정 이력 학습 → 처방 초안 정확도 지속 향상 → 개인화 프로토콜 진화

3.2 Agent 구성 및 역할

Agent명 역할 실행방식 의사개입
Screening Agent 닥터아이 결과 수신·위험도 분류 자동 ❌
Risk Scoring Agent X-ECAS 경동맥 위험도 계산 자동 ❌
Prescription Draft Agent EMR 오더셋 처방 초안 생성 자동 초안 ⚠️ 승인
Referral Agent 협진 의뢰서 자동 작성 자동 초안 ⚠️ 서명
Patient Notify Agent 결과 문자·앱 알림 발송 자동 ❌
Scheduler Agent 다음 방문 일정 자동 예약 자동 ❌
Alert Agent High-Risk 긴급 의사 알림 즉시 알림 🔴 필수
Learning Agent 처방 이력 학습·모델 개선 배치 자동 ❌

4. 3단계 임상 워크플로우

Stage 1 — 닥터아이 AI 안저검사

당뇨 외래 내원 시 E6670 코드로 안저촬영 시행. 닥터아이 AI가 5분 내 4대 안질환 분석 및 위험도 리포트 자동 생성 → EMR 팝업 연동. 정상 판정 시 6~12개월 후 자동 재방문 예약.

Stage 2 — 내과 조치 및 약물 처방 (이상 소견 시)

Prescription Draft Agent가 표준 프로토콜 기반 처방 초안 생성 (칼슘 도베실레이트 bid + 징코빌로바 추출물). 의사가 검토·수정 후 최종 승인. 동시에 X-ECAS 검사 오더 자동 생성.

Stage 3 — X-ECAS 위험도별 처치

LOW

🟢 저위험군

  • 기존 요법 유지
  • 생활습관 강화
  • 6~12개월 자동 추적
  • 자동 문자 안내 발송
INTERMEDIATE

🟡 중등위험군

  • 스타틴 처방 초안 자동 생성
  • 항혈소판제 추가 고려
  • 순환기내과 협진 의뢰서 초안
  • 의사 최종 승인
HIGH

🔴 고위험군

  • Alert Agent — 의사 즉시 알림
  • 뇌 MRI+MRA 의뢰 (의사 필수 승인)
  • 신경과·순환기내과 협진
  • 고강도 스타틴 처방

5. 세계 최초 포지셔닝 및 경쟁 우위

비교 항목 기존 의료 AI 닥터아이 Multi-Agent
AI 역할 단일 진단만 진단 → 처방 → 협진 → 알림 자동화
워크플로우 의사가 모든 단계 수동 처리 Multi-Agent 병렬·직렬 자동화
의사 역할 모든 결정 핵심 결정만 Human-in-the-Loop
학습 능력 정적 모델 처방 이력으로 지속 개인화 학습
EMR 연동 별도 입력 필요 위험도 기반 오더셋 자동 팝업
환자 관리 의사 기억·수동 Scheduler Agent 자동 추적 관리

🌏 2026년 현재, 안과 영역(특히 당뇨 눈 질환)에 Multi-Agent 오케스트레이션 + Human-in-the-Loop를 결합한 임상 워크플로우 시스템은 국내외 논문 및 상용 제품에서 발표된 바 없음. 세계 최초 출시 가능 영역.

8. 특허 및 지식재산 전략

특허 ① — 당뇨 눈 질환 Multi-Agent 자동화 진료 시스템

AI 안저진단 결과를 트리거로 복수 AI 에이전트가 병렬·직렬로 처방 초안·협진 의뢰·환자 알림·일정 관리를 자동 처리하는 의료 워크플로우 시스템 및 방법.

특허 ② — Human-in-the-Loop 기반 의료 AI 처방 승인 방법

AI 에이전트가 생성한 처방 초안에 대해 의사가 단계적으로 검토·수정·승인하는 구조의 의료 의사결정 지원 시스템.

특허 ③ — 안저 위험도와 경동맥 위험도 통합 스코어링 AI 시스템

X-eye 안저 AI 판독 결과와 X-ECAS 경동맥 초음파 데이터를 AI로 통합 분석하여 뇌졸중·심근경색 위험도를 복합 산출하는 방법.

특허 ④ — 의사 처방 이력 학습을 통한 개인화 EMR 오더셋 추천 방법

각 의사의 처방 패턴을 학습하여 맞춤형 오더셋을 자동 추천하는 적응형 AI 시스템.
