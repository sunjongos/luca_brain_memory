상황 분석: 나프타대란과 의료소모품 위기

1-1. 나프타대란이란?

중동 지역의 전쟁 장기화와 호르무즈 해협 봉쇄 등으로 석유화학 제품의 기초 원료인 '나프타(Naphtha)' 수급에 심각한 차질이 발생한 사태입니다. 나프타는 플라스틱, 비닐, 합성수지 등 수많은 석유화학 제품의 핵심 원료이기 때문에 공급망이 흔들리면서 일회용 의료기기와 필수 의료소모품 전반의 수급 불안정으로 직결되고 있습니다.

1-2. 의료소모품 영향 범위

품목 현황 위험도 NDB 영향
일회용 주사기 (3ml) 시장 품절 상태 심각 외래/입원 전 부서 일상 업무 마비 위험
수술용 장갑 가격 2배 이상 폭등 심각 정형외과/외과 수술 비용 직격탄
3000cc N/S (생리식염수) 공급 불안, 수량 제한 심각 관절경 수술 자체 중단 위기
약봉투 (약포지) 주문 차단/수량 제한 경계 약국 조제 업무 차질
거즈 단가 상승 (15~20%) 경계 처치/드레싱 비용 증가
수액 세트/수액 팩 품귀 및 가격 인상 경계 입원 환자 수액 치료 차질 우려
카테터/인공투석 튜브 공급 중단 위기 심각 중증 환자 치료 차질 (대체재 부족)

1-3. 구조적 문제: 별도 산정불가 품목의 함정

핵심 문제: 주사기, 주삿바늘, 소독용 거즈, 수액 세트 등 다빈도 사용 필수 소모품은 건강보험 제도상 의사의 행위료(수가)에 이미 포함된 '별도 산정불가' 품목입니다. 매년 수가는 1%대 인상에 그치는 반면, 소모품 단가는 한 번에 20%씩 급등 → 원가 상승분을 병원이 전액 부담하는 구조적 적자가 심화됩니다.

NDB 즉시 대응 전략 (D-Day ~ 2주)

긴급 Action 1: 비처방 재료대 - 소모품 업체 선결제 확보

  • 거래 소모품 업체에 선주문 + 선결제로 수술용 장갑, 주사기, 거즈 물량 우선 확보
  • 단일 업체 의존 탈피 → 최소 2~3개 유통사로 발주 분산
  • 일시적 단가 인상 수용하더라도 장기 공급 계약(월간/분기 단위) 체결하여 납품 우선순위 확보
  • 사후 정산제(선 사용 후 지불) 가능 품목은 적극 협의하여 재고 비용 부담 최소화

긴급 Action 2: 3000cc N/S - 도매상 영원팜 선주문/선결제

  • 도매상 영원팜에 관절경 수술용 3000cc N/S 2~4주분 물량 선주문 + 선결제
  • 수술 스케줄 기반으로 주간 소요량 산출 → 안전재고 2주분 확보 목표
  • 영원팜 외 대체 도매상 1곳 이상 발굴하여 유통채널 다변화
  • 수술 일정과 연동한 정기 납품 계약 체결 (주 1~2회 납품)
  • 3000cc N/S 품절 시 대안: 1000cc x 3개 조합 사용 가능 여부 의료진과 사전 협의

Action 3: 현재 재고 긴급 점검

  • 전 부서 비처방 재료대 현재고 일제 조사 (수술실, 외래, 병동, 약국, 물리치료실)
  • 품목별 잔여 재고일수 산출 (현재고 / 일평균 사용량)
  • 잔여 15일 미만 품목 즉시 긴급 발주
  • 과다 보유 부서 → 부족 부서로 내부 재배치

비처방 재료대 절약 캠페인

비처방 재료대(거즈, 주사기, 장갑 등)는 별도 산정불가 품목으로 원가 상승분을 병원이 전액 부담합니다. 공급 위기 상황에서 직원들의 적정 사용 인식을 높이는 캠페인이 비용 절감과 재고 연장에 직접적 효과를 줍니다.

물류관리 ERP 전산화 계획

5-1. 현재 문제점 (기존 방식의 한계)

기존 '발생주의 방식'에서는 부서 단위로 청구/관리하여 병원 전체의 실재고 현황 파악이 불투명합니다. 이로 인해 과다 재고, 사장(死藏), 누수 현상이 발생하고 결국 의료비 상승으로 이어집니다.

5-2. ERP 도입 목표

영역 기존 방식 ERP 전산화 후
품목 관리 수기 대장, 부서별 개별 관리 표준 코드 부여, 전사 통합 관리
청구 방식 일괄 청구 (불투명) 일반청구 / 정량보충 / 처방집계 표준화
재고 파악 월 1회 수기 실사 실시간 부서별 현장 재고 파악
발주 경험 기반 수동 발주 안전재고 기반 자동 발주 알림
유효기간 육안 확인 바코드/QR 연동 자동 추적
벤치마크 성과: 유사 규모 병원에서 MIS 재고관리 도입 후 의료소모품 재고자산 보유액 57% 감소 달성

5-3. NDB 맞춤 도입 방안 (소규모 병원 현실 반영)

클라우드 SaaS + 바코드 시스템 (저비용 전산화)

  • 자체 ERP 구축 대신 클라우드 기반 재고관리 SaaS 도입 (초기 비용 최소화)
  • 바코드 스캐너 도입으로 입/출고 + 유효기간 전산 연계
  • 기존 EMR/OCS 시스템과 연동하여 처방 → 재고 차감 자동화
  • 월 구독형 비용 구조로 초기 투자 부담 최소화

6-3. Antigravity 연동 구현 방안

기술 스택 및 구현 계획

  • 데이터 수집: 엠시스텍 EMR/OCS → 처방/재고 데이터 API 연동
  • AI 엔진: Antigravity Agent + ASMR 메모리 시스템 활용
  • 수요 예측 모델: 시계열 분석 (ARIMA/Prophet) + ML (XGBoost/LightGBM)
  • 외부 데이터: 나프타 시세 크롤링, 원자재 가격지수, 기상 데이터
  • 알림 채널: 텔레그램 봇 (기존 NDB 봇 활용) + 대시보드
  • 대시보드: AI 경영 관제 대시보드 (generate_ai_dashboard 스킬 활용)

실행 로드맵 및 우선순위

Phase 0: 긴급 대응 (즉시 ~ 1주)
- 영원팜 3000cc N/S 선주문/선결제 실행
- 소모품 업체 수술용 장갑/주사기 긴급 발주
- 전 부서 현재고 긴급 점검
- 약봉투 종이봉투 전환 시작
Phase 1: 절약 캠페인 (1~2주)
- "아끼면 이깁니다" 캠페인 전사 발표
- 부서별 적정 사용 가이드라인 배포
- 주간 소모량 모니터링 시작
- 유통채널 다변화 (대체 도매상 계약)
Phase 2: ERP 전산화 (1~3개월)
- 클라우드 SaaS 재고관리 시스템 도입
- 바코드 스캐너 설치 (중앙 창고 + 주요 부서)
- 품목 표준코드 부여 및 데이터 마이그레이션
- EMR/OCS 연동 개발
Phase 3: AI 물류 시스템 (3~6개월)
