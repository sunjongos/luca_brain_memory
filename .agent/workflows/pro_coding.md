**[사용 방법]**
채팅창에 `/pro_coding [개발 목표]` 형태로 입력하면, 기획부터 테스트 통과까지 5단계 교차 검증 코딩 프로세스가 가동됩니다.

## 🚀 5단계 전문 코딩 프로세스

### 1️⃣ [PLAN] 기획안 작성 (Luca 전담)
대표님의 지시를 받아 Luca가 요구사항을 심층 분석하고, 구현을 위한 기획 문서(Plan)를 프로젝트 내 `work-plan` (또는 `claude_task.md`) 파일로 작성합니다.

### 2️⃣ [REVIEW] 기획안 기술 검토 (Claude Code 전담)
Luca가 작성한 기획서를 깐깐한 수석 개발자 Claude Code가 리뷰하고, 놓친 엣지 케이스들을 보완합니다.
// turbo
`claude -p "현재 작성된 기획 문서(work-plan)를 꼼꼼히 리뷰해. 논리적 오류나 기술적 누락, 엣지 케이스가 있다면 파일의 하단에 피드백(Append)을 추가하고 저장해줘."`

### 3️⃣ [CODE] 실제 코드 구현 (Luca 전담)
보완이 완료된 최종 기획서를 바탕으로, Luca(Antigravity)가 직접 파일 시스템에 접근하여 실제 소스 코드를 수정 및 생성합니다.

### 4️⃣ [VERIFY] 완성 코드 리뷰 및 검증 (Claude Code 전담)
구현이 끝나면 Claude Code가 기획서와 작성된 실제 코드를 1:1로 대조하며, 버그나 누락된 부분이 없는지 깐깐하게 검증합니다.
// turbo
`claude -p "기획 문서의 내용과 방금 수정/생성된 실제 코드 파일들을 대조하면서 리뷰해. 기획대로 정확히 구현되었는지, 버그 소지는 없는지 파악하고 문제 발견 시 코드를 즉시 수정해."`

### 5️⃣ [TEST] 런타임 자동화 테스트 (TestSprite 전담)
최종 완성된 기능이 작동 환경에서 에러가 나지 않는지, Claude Code가 TestSprite MCP를 호출하여 자동화 테스트를 수행합니다.
// turbo
`claude -p "TestSprite MCP를 사용해서 방금 구현을 완료한 기능이 에러 없이 정상적으로 작동하는지 자동화 테스트를 실행하고, 통과했으면 '테스트 완료'를 알리고 종료해."`
