---

**[사용 방법]**
`/pair_coding [코딩 과제 내용]` 형태로 호출하시면, Luca 부장이 기획하고 Claude Code가 코드를 작성하는 풀자동화 사이클이 돌아갑니다.

1. **[요구사항 분석 및 기획] (Luca 부장 전담)**
   대표님이 지시하신 과제를 심층 분석하고, 필요시 코드베이스 구조를 파악하거나 관련 레퍼런스를 탐색합니다.

2. **[작업 지시서 작성] (Luca 부장 전담)**
   Claude Code가 완벽하게 이해하고 즉시 코딩에 돌입할 수 있도록, 아주 구체적이고 논리적인 작업 지시서(`claude_task.md`)를 작성합니다.

3. **[Claude Code 자동 실행] (자동화 구간)**
   작성된 지시서를 바탕으로 백그라운드 환경에서 Claude Code(CLI) 인스턴스를 즉시 호출하여 코딩 실무를 전담시킵니다.
   // turbo
   `claude -p "현재 디렉토리에 있는 claude_task.md 파일의 지시사항을 처음부터 끝까지 읽고, 모든 코드 구현 및 수정을 완료해줘. 테스트까지 모두 통과하면 종료해."`

4. **[결과 검증 및 인수인계] (Luca 부장 전담)**
   Claude Code의 실행이 성공적으로 완료되면, 변경된 코드 라인이나 구조를 빠르게 훑어보고 대표님께 최종 완성본을 브리핑(보고)합니다.
