# 📧 Email Summary & Reply Workflow

대표님이 "메일 요약해줘" 또는 "받은 메일 확인해줘" 라고 하면 실행합니다.

## Workflow Steps

// turbo
### Step 1: 미확인 메일 자동 조회

```powershell
python ".agent/skills/google_workspace/get_emails.py" --count 10 --unread
```

### Step 2: Luca 메일 분류 및 우선순위 판단

조회된 메일을 아래 기준으로 자동 분류합니다:

| 우선순위 | 기준 |
|----------|------|
| 🔴 즉시 처리 | 미팅 요청, 계약/결제 관련, 중요 파트너 |
| 🟡 오늘 내 처리 | 일반 업무 협조, 문의 |
| 🟢 나중에 처리 | 뉴스레터, 알림, 참고용 |

### Step 3: 브리핑 보고

```
📬 Gmail 메일 브리핑 (읽지 않은 메일 N개)

🔴 즉시 처리 필요 (N개):
  1. [발신자] — [제목]
     요약: [핵심 내용]
     
🟡 오늘 내 처리 (N개):
  ...
  
🟢 참고용 (N개):
  ...
```

### Step 4: Human-in-the-Loop — 회신 처리

🔴 즉시 처리 메일에 대해 대표님께 확인:
> "대표님, [발신자]의 메일에 회신이 필요해 보입니다. 회신 초안을 작성해드릴까요?"

대표님 승인 후에만 회신/발송 진행합니다.
