# 🧠 Ontology (Knowledge Graph) Skill

이 스킬은 복잡하고 다차원적인 업무 지식을 단순 텍스트나 관계형 DB가 아닌 **그래프 형태(주어-동사-목적어)**로 저장, 질의, 추론하기 위해 사용됩니다. 

## 🌟 주요 특징 (Core Philosophy)
1. **LLM 한계 돌파**: 단독으로는 분석 불가능한 5개 이상의 이종 데이터(다양한 부서 및 기기 데이터)를 결합하여 온톨로지 기반 추론을 수행합니다.
2. **절대 팩트 기반 (투명성)**: 추론 로직의 투명성을 제공하며, **"도출된 데이터 인사이트는 절대 거짓말을 하지 않습니다."** (LLM 환각 방지)
3. **명확한 지식 표현**: RDF(Resource Description Framework) 형식을 기반으로 지식 간의 계층(`subClassOf`) 및 연관 관계를 정의합니다.
4. **다중 추론 능력**: "A는 B의 하위 질환이고 B는 C의 증상이다"는 규칙을 바탕으로 A와 C의 관계를 AI가 스스로 추론할 수 있게 돕습니다.
5. **SSOT (Single Source of Truth)**: 닥터아이 프로젝트 등에서 발생하는 수많은 의료 데이터, 관련자(의사, 환자, 개발사), 질병의 상관관계를 하나의 그래프 망으로 일관성 있게 통합합니다.

## 🛠 구성 요소
- `ontology_manager.py`: 지식 그래프(Graph)를 생성, 로드하고 SPARQL 쿼리 등을 수행하는 핵심 파이썬 스크립트. (`rdflib` 라이브러리 사용)
- `doctor_eye_base.ttl`: 닥터아이(Doctor Eye) 프로젝트의 기본 구조와 정보를 담고 있는 초기 온톨로지 정의 파일(Turtle 포맷).

## 🚀 사용 방안 (닥터아이 프로젝트 적용)

### 1단계: 온톨로지 기본 설계 구축
남양주백병원, 파이헬스케어 실무진(이영규 대표, 이순태 교수 등)과 프로젝트 요소, 진단 항목(알츠하이머, 파킨슨, 뇌동맥류 등) 간의 연결 고리를 정의합니다.
### 2단계: 자동 질의 및 데이터 연계 (SPARQL)
에이전트가 `ontology_manager.py`를 호출하여 "안저 카메라 이미지로 진단할 수 있는 뇌 질환 모델" 등을 지식 그래프 상에서 검색(Query)합니다.
### 3단계: AI 에이전트 추론 결합
RAG(검색 증강 생성)에 지식 그래프를 결합한 **GraphRAG**형태로, 에이전트가 환각(거짓 정보) 없이 의료/비즈니스 질문에 답변하도록 만듭니다.
