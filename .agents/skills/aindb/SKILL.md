# AIndb (Namyangju Baek Hospital AI Agent)

## Description
남양주백병원 전산팀에서 배포하고 관리하는 전직원 공용 AI 업무 에이전트 스킬입니다. 업무 자동화, 경영 지침 준수, 실시간 매뉴얼 연동을 지원합니다.

## Capabilities
- **Management Sync**: 중앙 서버와 연동하여 글로벌 인스트럭션 실시간 업데이트.
- **Workflow Automation**: 병원 행정 및 진료 지원 업무 프로세스 자동 설계 및 실행.
- **Knowledge Retrieval**: 병원 내부 규정 및 의학 매뉴얼 기반 지식 추출.

## Installation Requirement
- Antigravity Enterprise Runtime
- Internal Network Connectivity to `Port: 8888` (Hospital Central Server)

## Usage
- "AIndb, 오늘의 주요 공지 사항 확인해줘"
- "퇴원 환자 안내문 초안 작성해줘 (병동 규정 적용)"
- "주간 병상 가동률 리포트 생성해"
