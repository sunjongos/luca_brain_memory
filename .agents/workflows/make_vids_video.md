# Google Vids 영상 제작 자동화 워크플로우

1. **사전 준비**:
   - 대표님으로부터 변환할 텍스트 스크립트(주제, 본문, 강조점 등) 혹은 요약 문서(가정통신문, 홍보글 등)를 제공받습니다.
   - 혹시 Vids에서 사용할 특정 문서가 이미 Google Drive에 있다면 관련 링크를 확인받습니다.

2. **브라우저 자동화 시작 (Google Vids 접속)**:
   - `mcp_luca_computer_browser_navigate` 도구를 사용하여 `https://vids.google.com` (또는 Vids 접근 허용 링크)에 접속합니다.
   - 구글 계정 로그인이 필요한 경우 기존 세션을 사용하거나 필요시 로그인 과정을 RPA로 제어합니다.

3. **영상 생성 명령 (프롬프트 및 에셋 입력)**:
   - 브라우저 제어(클릭, 타이핑) 기능을 사용하여 '새 동영상 만들기' (Create new video) 버튼을 누릅니다.
   - 대표님이 제공해주신 대본 내용을 프롬프트 입력창에 `mcp_luca_computer_browser_type_text` 등으로 붙여넣고 영상 생성을 시작합니다.

4. **검토 및 편집 (렌더링 대기)**:
   - Vids의 AI가 동영상 스토리보드와 초안을 생성하는 과정을 기다립니다 (`mcp_luca_computer_browser_sleep` 등 사용).
   - 생성된 스크립트 기반 나레이션 적용이나 템플릿(BGM, 스타일) 설정이 필요하면 자동 클릭으로 처리합니다.

5. **결과물 추출 및 보고**:
   - 영상이 완료되면 우측 상단의 '내보내기' (Export) 버튼을 눌러 MP4 형식으로 다운로드합니다.
   - 루카는 내부 작업 폴더에 수신된 MP4 파일의 절대 경로를 확인하고, 대표님께 완료 보고를 올립니다. (원하는 경우 텔레그램 등을 통해 파일 전송을 시도하거나 구글 드라이브 링크로 전달합니다.)
