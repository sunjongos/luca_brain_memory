# 📰 보도자료 자동 생성 워크플로우 (Press Release Automation)

이 워크플로우는 사용자가 신문기사나 보도자료 작성을 요청했을 때, 정해진 규격(HTML, DOCX)으로 파일을 자동 생성하고, '나노바나나2.0' (또는 최적화된 이미지 생성 프롬프트) 스타일의 썸네일/보도자료용 이미지를 함께 첨부하도록 강제하는 지침입니다.

## ⚙️ 실행 조건
- 사용자가 "신문기사 써줘", "보도자료 작성해", "/press_release" 등의 요청을 할 때 자동 트리거됩니다.

## 📋 단계별 실행 지침

### 1단계: 내용 구성 및 HTML 파일 생성
- 제공된 초안이나 지시사항을 바탕으로 언론사 보도자료 톤앤매너(객관적, 신뢰성, 헤드라인 강조)에 맞게 텍스트를 다듬습니다.
- 주요 인사 멘트는 **Blockquote** 처리하여 시각적으로 돋보이게 합니다.
- 내용을 바탕으로 반응형 웹 디자인이 적용된 단일 `index.html` (또는 지정된 이름의 `.html`) 파일을 생성합니다.
- 웹 페이지는 최신 뉴스 포털(예: 네이버 뉴스)의 UI 스타일을 차용하여 깔끔하게 구성합니다.

### 2단계: DOCX 파일 생성 (한글/워드용)
- 언론사에 배포하기 쉽도록 동일한 텍스트 내용을 Word 문서(`.docx`) 형태로 가공하여 저장합니다.
- Python의 `python-docx` 라이브러리를 활용하거나, Markdown에서 변환하는 방식을 사용하여 지정된 폴더에 저장합니다.
- (기존의 HWP 파일 생성 지침은 **DOCX 파일 생성**으로 수정되었습니다.)

### 3단계: 나노바나나 2.0 스타일 이미지 생성
- 보도자료 내용(예: 스마트 AI 병원, 업무 효율성, 모바일 EMR 등)을 가장 잘 표현하는 썸네일 이미지를 생성합니다.
- `generate_image` 툴을 사용하며, 프롬프트 작성 시 **"나노바나나2.0 스타일(밝고 트렌디하며 가독성이 높은 고품질 3D/일러스트 렌더링 또는 전문적인 포토얼리스틱 스타일)"**을 명시하여 시각적으로 우수한 이미지를 생성합니다.
- 생성된 이미지를 HTML 내부에 `<img>` 태그로 자동 삽입하거나, 별도의 첨부 파일로 제공합니다.

### 4단계: 결과 보고
- 작업이 끝나면 생성된 HTML 경로, DOCX 경로, 그리고 이미지 결과를 사용자(대표님)에게 보고합니다.
