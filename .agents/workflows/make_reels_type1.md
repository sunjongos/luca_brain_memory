# 릴스 1 (신속 4컷 전환형) 워크플로우

1. **사전 준비**:
   - `caption.txt` 파일에 확정된 인스타그램 본문과 TTS 더빙용 멘트가 준비되어 있어야 합니다.
   - 제미나이 등을 통해 생성된 4컷의 16:9 웹툰(또는 기타 형식) 이미지가 준비되어 있어야 합니다.

2. **에셋 수집 및 확인**:
   - 대표님께 4장의 이미지를 순서대로 업로드 받아 내부 작업 디렉토리에 저장하거나, 대표님이 특정 폴더에 다운로드 받으셨는지 경로를 확인합니다.
   - TTS로 읽을 멘트를 최종 명시하여 승인을 받습니다.

3. **BGM 선정**:
   - 에이전트가 보유한 내부 BGM 리스트 중 영상 분위기에 가장 잘 맞는 라이브러리 음악을 제안하고 1곡을 최종 승인받습니다.

4. **오디오/비디오 자동 병합 렌더링**:
// turbo
   - `python "C:\Users\USER\OneDrive\바탕 화면\luca연구에이전트\Reels_Automation\make_reels_type1.py"` 스크립트를 백그라운드로 실행하여 조립을 시작합니다.
   - 에이전트는 스크립트 실행 후 `command_status`를 통해 작업 완료를 확인합니다.

5. **결과 보고**:
   - 렌더링 완료가 확인되면, 에이전트는 결과물(MP4)이 저장된 최종 날짜 폴더의 절대 경로를 대표님께 텍스트로 보고하여 즉시 인스타그램 앱으로 업로드 하실 수 있도록 안내합니다.
