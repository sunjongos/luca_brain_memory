# 홈페이지 개선 원스톱 워크플로우

## 1. 프로젝트 폴더 세팅
```
백병원_홈페이지개선/
├── README.md                    ← 전체 가이드 (링크, 의료진, 핵심정보)
├── 01_분석보고서.md              ← 현재 사이트 문제점 분석
├── 02_히어로섹션_초안.html        ← 완성 HTML 시안 (독립 실행 가능)
├── 03_히어로섹션_디자이너지시서.md ← 웹디자이너 작업 지시서
├── 신규_슬라이드/               ← 섹션별 개별 HTML 코드
├── 원본_소스/                   ← 원본 사이트 소스 참조
└── assets/                      ← 이미지·아이콘
```

## 2. 분석 단계
- `read_url_content`로 원본 사이트 구조 파악
- 메뉴 링크, 센터 명칭, 진료시간, 전화번호 수집
- `01_분석보고서.md` 작성

## 3. 콘텐츠 기획 (대표님과 협의)
- 슬라이드/섹션 구성 확정
- 핵심 메시지, 의료진 이름·전문분야·경력 정리
- 포인트 컬러, 디자인 방향 결정

## 4. HTML 완성본 제작
- **단일 독립 HTML 파일** (CSS+JS 내장, 외부 파일 불필요)
- Noto Sans KR 폰트 (Google Fonts CDN)
- 상단 신뢰 스크롤 바 (병원 핵심 자산 노출)
- 슬라이드: 자동전환(6.5초) + 터치 스와이프 + 화살표 + 도트 네비
- 모바일 반응형 (768px 이하)
- 환자 페인포인트 직격 카피 ("서울까지 갈 필요 없습니다" 등)

## 5. 웹디자이너 지시서 작성
`03_히어로섹션_디자이너지시서.md` 에:
- 각 슬라이드별 헤드라인·본문·태그·CTA 버튼 명세
- 컬러 코드, 링크 URL
- 원본 유지/신규 제작 구분

## 6. ZIP 압축
```powershell
Compress-Archive -Path ".\[프로젝트폴더]" -DestinationPath ".\[프로젝트]_웹디자이너전달.zip" -Force
```

## 7. Gmail API로 이메일 발송
- `send_email_designer.py` 사용 (c:\Users\USER\OneDrive\바탕 화면\luca연구에이전트\)
- `credentials.json` → OAuth 인증 → `gmail_token.json` 저장됨
- 발신: sunjongos@gmail.com
- 재사용 시: `gmail_token.json` 있으면 자동 로그인 (재인증 불필요)

```bash
python send_email_designer.py
```

## 핵심 원칙
- **임팩트 카피**: 환자 페인포인트 직접 공략 ("다른 병원에서 포기하셨나요?")
- **독립 실행 HTML**: 웹디자이너가 파일 하나만 열면 확인 가능
- **원본 유지 vs 신규**: 잘 되는 것은 건드리지 말 것
- **센터 명칭**: 실제 홈페이지 구조 파악 후 정확히 반영
