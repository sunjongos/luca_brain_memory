# 🏥 의료 언론기사 자동 작성 워크플로우 (Medical Article Generation)

이 워크플로우는 사용자가 **'의료 언론기사'**, **'병원 보도자료'**, **'의학 칼럼'** 등 의료 지식이 포함된 공식 기사 작성을 요청했을 때 트리거되며, 일반 보도자료 생성과는 달리 **반드시 '의학적 팩트체크(Fact-Check)' 과정**을 선행하도록 강제합니다.

## ⚙️ 실행 조건
- 사용자가 "의료 언론기사 작성해줘", "의학 칼럼 써줘", "/medical_article_generation" 등의 요청을 할 때 자동 트리거됩니다.

## 📋 단계별 실행 지침

### 1단계: 의학적 팩트체크 및 검증 (CRITICAL)
- 사용자가 제시한 '질환', '치료법', '약물', '의학적 기전(예: HPA 축, 코르티솔 등)'에 대해 기사 작성 전 **반드시 자체 검증 단계를 거칩니다.**
- 필요한 경우 `search_web` 툴이나 내부 지식을 활용하여 해당 치료법이나 주장이 현대 의학적 근거(EBM)에 부합하는지, 과대광고 소지가 없는지 검토합니다.
- 검증 결과 의학적으로 논란이 있거나 위험한 내용이 포함된 경우, 작성 전 사용자에게 즉각 경고 및 대안을 제시합니다.

### 2단계: 기사 톤앤매너 설정 및 내용 구성
- 검증된 팩트를 바탕으로 전문적인 의학 칼럼 또는 언론사 보도자료 포맷으로 텍스트를 구성합니다.
- 주요 의료진(원장님)을 저자로 명시하고 멘트나 강조점을 적절히 배치합니다. (예: "남양주백병원 뇌신경센터 강진호 병원장은...")
- 환자들이 이해하기 쉬운 언어로 변환하되, 전문성을 잃지 않는 문체를 유지합니다.

### 3단계: HTML 및 DOCX 포맷 파일 자동 생성
- **HTML 생성**: 가독성 높은 반응형 웹 스타일(제목, 카테고리, 본문 하이라이트 문구 처리)을 적용한 단일 HTML 파일을 생성합니다.
- **DOCX 생성**: Python `python-docx` 라이브러리를 통해 언론사에 즉시 배포 가능한 형태로 깔끔하게 스타일링(맑은고딕 폰트 등)된 Word 문서를 생성합니다.
- 결과물은 대표님이 지정한 폴더(예: "언론기사/YYYY년 M월 언론기사")에 일괄 저장합니다.

### 4단계: 결과 보고 및 리뷰 요청
- 생성된 파일의 절대 경로와 함께 완료 메시지를 전달합니다.
- 대표님(사용자)에게 "의학적 검증을 마쳤으나, 최종 배포 전 원장님들의 감수를 권장합니다"라는 안내 멘트를 반드시 포함하여 보고합니다.
