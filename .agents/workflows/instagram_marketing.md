# 인스타그램 마케팅 통합 워크플로우 (SOP)

이 워크플로우는 대표님과 AI(루카)가 협업하여 인스타그램 콘텐츠(게시글/릴스)를 기획하고 렌더링한 뒤, 수동 업로드 기기에 최종 에셋을 전달하는 표준 절차입니다. 

## 1. 게시글(대본) 공동 작성
- AI와 대표님이 협업하여 타겟 고객(환자)에 맞는 인스타그램 본문, 릴스 멘트(TTS용), 그리고 해시태그를 기획합니다.
- 확정된 텍스트는 `caption.txt` 파일로 준비합니다.

## 2. 콘텐츠 유형별 에셋 생성
**A. 일반 이미지 게시물인 경우**
- AI가 대표님이 승인한 프롬프트(예: 웹툰 로맨스 작화 등)를 바탕으로 고화질 이미지를 생성합니다.

**B. 릴스(Reels) 영상인 경우 (2-Track 무기화 전략)**
- **[핵심 운영 전략]**: 하나의 게시글과 키 이미지를 기획한 후, **[릴스 1]**과 **[릴스 2]**를 모두 제작하여 인스타그램 타겟층에 맞게 전략적으로 교차 업로드하는 것을 표준으로 삼습니다.
- **[릴스 1: 신속 4컷 전환형]**: AI와 대표님이 호흡을 맞추는 Human-in-the-Loop 방식입니다.
  1. [Text Confirm]: 대본/해시태그 초안 작성 후 대표님 승인
  2. [Image Confirm]: 생성된 웹툰 이미지 4컷 확인 후 대표님 승인
  3. [BGM Confirm]: 제안된 배경음악 확인 후 대표님 승인
  4. 3단계 승인이 완료되면 파이썬 스크립트가 자동 병합 (`make_reels_type1.py` 가동).
- **[릴스만들기 2: Labs Flow 프리미엄]**: 압도적인 영상미의 통짜 영상을 만드는 최고급 파이프라인입니다.
  1. [게시글/대본 작성]: AI가 인스타 본문과 릴스 더빙(TTS) 대본을 선작성하여 확정합니다.
  2. [키 이미지 생성]: 대본에 맞는 핵심 장면(Key Image)의 프롬프트를 도출하고 기준 이미지를 우선 생성합니다.
  3. [Flow 렌더링]: 대표님이 해당 키 이미지를 Google Labs Flow에 얹어 VEO 3 영상으로 뽑아낸 뒤 1회 다운로드합니다.
  4. [Lyria 생성]: 영상에 어울리는 배경음악을 생성해 다운로드합니다.
  5. [Watcher 조립]: 대표님의 다운로드 폴더에 영상과 음악이 쌓이는 순간, AI 감시요원이 낚아채 오디오(TTS+BGM)를 믹싱하여 자동 완성!

## 3. 최종 결과물 Export 및 수동 업로드
- 메타(Meta)의 강력한 봇 보안 정책에 의해, 계정 정지 위험이 있는 봇 자동 업로드는 **절대 진행하지 않습니다**.
- 생성된 모든 최종 결과물(텍스트, 이미지 PNG, 릴스 MP4)은 아래 로컬 디렉토리의 날짜 폴더에 자동 저장됩니다:
  👉 `C:\Users\USER\OneDrive\바탕 화면\SNS\인스타\YYYYMMDD`
- 대표님 혹은 담당 직원이 해당 폴더에서 파일을 확인하고 스마트폰 앱을 통해 안전하게 직접 포스팅합니다.
